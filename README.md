# 윈드러너 키우기 - 가이드 미션 자동화 (이미지 컨트롤)

MuMu Player에서 돌아가는 「윈드러너 키우기」의 **가이드 미션 보상 수령과 소환 미션**을 자동화하는 Python 스크립트.

**이미지 컨트롤** 방식으로 동작한다. 게임 내부 데이터나 메모리는 건드리지 않는다.
ADB로 화면을 캡처한 뒤 OpenCV 템플릿 매칭과 색상 판정으로 화면 상태를 인식하고,
조건문에 따라 ADB 터치/키 입력을 보낸다.

> ⚠️ 매크로·자동화 사용은 게임 이용약관에 어긋날 수 있다. 사용에 따른 책임은 사용자에게 있다.
> 개인 학습용 예제로 공개한다.

## 설치 방법 (그대로 따라 하기)

코드를 몰라도 됩니다. 아래 명령어를 **복사해서 붙여넣기**만 하면 됩니다.
설치가 끝나면 **바탕화면에 `windrunner` 폴더**가 생기고, 프로그램은 그 안에 들어갑니다.

### 준비
| 항목 | 내용 |
|---|---|
| 컴퓨터 | Windows 10 또는 11 |
| 에뮬레이터 | MuMu Player (기본 경로에 설치) |
| 화면 크기 | MuMu 설정 → 화면 → 해상도 **세로(모바일) 900x1600** |

### 1단계. PowerShell 열기
키보드에서 `윈도우 키`를 누르고 `powershell`을 입력한 뒤 `Enter`를 누릅니다.
파란색(또는 검은색) 창이 뜨면 됩니다.

### 2단계. 아래 한 줄 붙여넣기
아래 한 줄을 복사해서 PowerShell 창에 붙여넣고(마우스 오른쪽 클릭) `Enter`를 누릅니다.
```powershell
[Net.ServicePointManager]::SecurityProtocol = 'Tls12'; irm https://raw.githubusercontent.com/l1539ym-cyber/windrunner-guide-auto/main/install.ps1 | iex
```
아래 과정이 **자동으로** 진행됩니다. (처음에는 3~5분 정도 걸립니다)

| 순서 | 하는 일 |
|---|---|
| 1/4 | Python이 없으면 설치. `winget`이 있으면 winget으로, **없으면 python.org에서 직접 내려받아** 설치 |
| 2/4 | 바탕화면을 찾아(OneDrive 바탕화면 포함) `windrunner` 폴더를 만들고 최신 프로그램을 내려받음 (**Git 필요 없음**) |
| 3/4 | 필요한 부품(opencv-python, numpy) 설치 |
| 4/4 | `windrunner` 폴더 창을 열어 줌 |

`[4/4] 설치 완료`가 뜨고 `windrunner` 폴더 창이 열리면 끝입니다.
> 설치 스크립트 내용은 이 저장소의 [`install.ps1`](install.ps1)에서 확인할 수 있습니다.

### 3단계. 실행
1. MuMu Player에서 게임을 켜고 **기본(전투) 화면**을 띄워 둡니다.
2. 바탕화면 `windrunner` 폴더에서 **`run_guide.bat`을 더블클릭**합니다.
3. 검은 창에 `시작 - 기기 ...`가 뜨면 동작 중입니다. 끄려면 그 창에서 `Ctrl + C`를 누르거나 창을 닫습니다.

> MuMu 창은 **최소화하지 마세요.** 최소화하면 자동으로 일시정지됩니다.
> 대신 **다른 창(브라우저 등) 뒤에 가려 두는 것은 괜찮습니다.** 가려져 있어도 정상 동작합니다.

### 새 버전으로 업데이트 → **자동입니다**
버그가 고쳐진 새 버전이 올라오면 **프로그램이 알아서 받아서 적용합니다.** 따로 할 일이 없습니다.
- `run_guide.bat`을 실행할 때마다 먼저 새 버전이 있는지 확인하고, 있으면 업데이트한 뒤 시작합니다.
- 켜 둔 상태에서도 **1시간마다** 확인합니다. 새 버전이 있으면 뽑기 같은 동작 중이 아닌 기본 화면일 때
  잠깐 멈추고 업데이트한 뒤 **자동으로 다시 시작**합니다. 검은 창에 `[업데이트] 새 버전 발견 ...`이 표시됩니다.
- 로그(`logs/`)와 개인 설정(`user_settings.py`)은 업데이트해도 그대로 남습니다.

> **2026-11-11 이전에 설치하신 분**은 자동 업데이트 기능이 없는 버전입니다.
> **2단계의 한 줄을 한 번만 다시 붙여넣어** 주세요. 그 뒤로는 자동으로 업데이트됩니다.

### 잘 안 될 때
| 증상 | 해결 |
|---|---|
| 빨간 글씨로 `설치 실패` / `오류 내용` | 인터넷 연결을 확인하고 2단계 한 줄을 다시 붙여넣기 |
| Python 설치에서 멈춘 것 같음 | 1~3분 걸릴 수 있음. 5분이 넘으면 창을 닫고 2단계를 다시 실행 |
| `irm` 또는 `iex`를 찾을 수 없다고 나옴 | 명령 프롬프트(cmd)에 붙여넣은 것. 1단계대로 **PowerShell**을 열어 다시 붙여넣기 |
| `run_guide.bat` 실행 시 `Python 을 찾을 수 없습니다` | 2단계를 다시 실행 |
| `연결된 안드로이드 기기가 없습니다` | MuMu Player가 켜져 있는지 확인 |
| `adb.exe 를 찾을 수 없습니다` | MuMu를 기본 경로가 아닌 곳에 설치한 경우. `guide_auto.py` 위쪽 `ADB_CANDIDATES`에 경로 추가 |

## 동작 방식

### 기본 화면이란
아래 요소가 보이는 **전투 화면**을 "기본 화면"으로 본다. 기본 화면일 때만 미션 패널을 누른다.

- 왼쪽 아래 **채팅 아이콘** (필수)
- 오른쪽 **이벤트**, **랭킹 보드**, 왼쪽 **패스**, 위쪽 **챕터** 표시 중 2개 이상
- 화면 중앙 아래의 **[가이드]** 또는 **[반복]** 미션 패널

메뉴·미션 창·채팅창·상점·길드 같은 화면이 열리면 채팅 아이콘이 가려지므로 "기본 화면 아님"으로 판단하고 기다린다.

### 판정 순서 (5초 주기)
```
매 주기:
  if   MuMu 창이 최소화됨                → 일시정지 (복원되면 3초 후 재개)
  elif 직전 뽑기 후 아직 복귀 못 함       → 기본 화면까지 빠져나오기부터 계속
  elif 패배 화면 ('Defeat' + '재도전')    → '재도전' 탭 (10분 안에 3번 패배하면 더 누르지 않음)
  elif 기본 화면
        if   [반복] 미션 패널             → 패널 탭 = 모험 코인 즉시 수령 (뽑기 안 함)
        elif [가이드] 클리어 (초록 진행도 / 분홍 테두리 / 빨간 +N 표시) → 패널 탭 = 보상 수령
        elif [가이드] ○○ 소환 (캐릭터/소환수/탈것)
              → 패널 탭 → 소환 화면 30회 비용 확인
                 뽑기권이면 '30회' 탭 → 10초 대기 → 기본 화면까지 빠져나오기
                 보석이면 이미 뽑은 것 → 누르지 않고 빠져나오기
        else (진행 중 / 패널 안 보임)      → 대기
  else 기본 화면이 아님 (채팅, 길드, 상점, 메뉴 등) → 대기 (아무것도 누르지 않음)
                                                      기본 화면으로 돌아오면 자동 재개
```

### 패배했을 때
패배하면 붉은 "Defeat" 창과 함께 **"이전 스테이지 반복"**, **"재도전"** 버튼이 뜬다.
그대로 두면 10초 뒤 이전 스테이지로 돌아간다. 스크립트는 이 창을 인식하면 **"재도전"** 을 누른다.
단, 10분 안에 3번 패배하면 아직 이기기 어려운 스테이지로 보고 더 누르지 않는다.
그러면 게임이 알아서 이전 스테이지로 돌아간다. (`RETRY_ON_DEFEAT`, `RETRY_LIMIT`으로 조절)

### 가이드 미션 순환 (예시)
`콤보 50회 달성` → `일반 몬스터 27마리 처치` → `콤보 달성` → `일반 몬스터 27마리 처치` → `콤보 50회 달성` → `○○ 소환(30회)` → 반복

소환 미션 직전에 해당 종류의 30회 뽑기권이 지급되므로 따로 재화를 확인하지 않는다.

### 뽑기 후 기본 화면으로 빠져나오기
| 화면 | 처리 |
|---|---|
| 소환 결과 (카드 30장) | '터치하여 닫기' 탭 (이 화면은 ESC가 먹지 않음) |
| **'신규' 획득 연출** (새 캐릭터/소환수/탈것, 노란 빛 + "신규") | 화면 어디에 있든 **'터치하여 닫기' 등 닫기 문구를 찾아** 그 위치를 탭 |
| 소환 화면 | ESC (`KEYCODE_ESCAPE`) 한 번 → 3초 대기 후 다시 확인 |
| 모르는 화면이 약 7초 이상 계속됨 | 화면을 `logs/`에 저장하고 하단 중앙(닫기 문구 기본 위치)을 한 번 탭 |
| 기본 화면 | 복귀 완료 |

닫기 문구는 `templates/close_text/` 폴더에 있는 이미지를 **전부** 사용한다.
흰 글자만 뽑아 살짝 흐리게 처리한 뒤, 0.7~1.5배 크기로 화면 전체를 탐색한다.
글자 크기와 위치가 달라도 찾을 수 있다.
"화면을 눌러 돌아가기"처럼 다른 문구가 나오는 화면이 있으면, 그 글자 부분만 잘라 이 폴더에 넣으면 된다.
```bash
python adbtool.py cap new_screen.png   # 현재 화면 캡처 → 글자 부분만 잘라 templates/close_text/ 에 저장
```

### 자동 업데이트
```
run_guide.bat → run.py (실행 관리자)
  ├ 시작 시: updater.py 가 GitHub 최신 커밋과 .version 비교 → 다르면 그 커밋 ZIP 을 받아 프로그램 파일 덮어쓰기
  └ guide_auto.py 실행
       ├ 1시간마다 새 버전 확인 → 있으면 '기본 화면일 때' 종료 코드 3 으로 종료
       │    → run.py 가 업데이트 후 즉시 다시 실행
       ├ 오류로 종료 → 10초 후 다시 실행
       └ Ctrl+C → 끝
```
- Git이 없어도 됩니다 (ZIP으로 받음). `logs/`, `user_settings.py`, `.version`은 덮어쓰지 않습니다.
- 실행 중인 bat 파일이 업데이트로 바뀌어도 깨지지 않도록, 재시작과 업데이트는 Python(`run.py`)이 맡습니다.
- `.git` 폴더가 있는 개발용 폴더(직접 `git clone`한 경우)에서는 자동 업데이트하지 않습니다. `git pull`로 직접 받으세요.

### 오류 자동 복구
오류가 나도 사람이 손대지 않게, 스크립트가 스스로 원인을 확인하고 단계적으로 복구한다.
복구할 때마다 로그에 `[자동복구]`로 남기고, 그 순간 화면을 `logs/autoheal_*.png`로 저장한다.
이 캡처는 `bug_report.bat`으로 만드는 제보 ZIP에도 함께 들어간다.

| 상황 | 자동 복구 |
|---|---|
| ADB 연결 끊김 (화면 캡처 실패 등) | 바로 기기 다시 연결 → 3회 연속 실패면 **ADB 서버 재시작** → 6회 이상이면 MuMu가 꺼졌는지 확인하고 30초 간격으로 계속 재시도 |
| 게임이 꺼졌거나 다른 앱이 앞에 있음 | 약 30초마다 확인, 2번 연속이면 **게임 다시 실행** 후 40초 로딩 대기 |
| 기본 화면이 아닌 같은 화면이 3분 넘게 그대로 | 화면 저장 후 **ESC 한 번** (멈춘 팝업 닫기, 같은 화면에선 한 번만) |
| 뽑기 후 기본 화면 복귀가 3번 연속 실패 | 복귀 시도를 멈추고 위의 "멈춘 화면" 처리에 맡김 |
| 알 수 없는 오류 3번 연속 | 화면 저장 후 내부 상태 초기화 |
| 스크립트 자체가 오류로 꺼짐 (MuMu가 아직 안 켜짐 등) | `run_guide.bat`이 **10초 뒤 자동으로 다시 실행** (완전히 끄려면 창을 닫기) |

### 인식 방법
스테이지마다 배경색이 달라도 흔들리지 않도록 **글자 색깔만 뽑아서** 판정한다.

| 대상 | 방법 |
|---|---|
| 기본 화면 | 채팅 아이콘, 이벤트, 랭킹 보드, 패스, 챕터 아이콘 템플릿 매칭 (`templates/hud/`) |
| `[가이드` 패널 | **주황색** 글자만 남긴 마스크로 매칭 (패널 0.89~1.00 / 그 외 ≤0.27) |
| `[반복]` 패널 | **하늘색** 글자만 남긴 마스크로 매칭 |
| 클리어 여부 | ① 진행도 `(30/30)`의 **초록색** 글자 픽셀 수 (클리어 약 810 / 진행 중 0)<br>② 진행도 숫자가 없는 미션(예: `모험 챕터 476-15 클리어`)은 패널 **분홍 테두리** (클리어 0.72 이상 / 진행 중 0.00)<br>③ 패널 오른쪽 위 **빨간 `+N` 표시** (보조. 클리어여도 표시가 없을 때가 있음) |
| 소환 미션 여부 | 문구 속 '소환' **흰** 글자 마스크 매칭 |
| 이미 뽑았는지 | 소환 화면 '30회' 버튼의 비용이 **보석 아이콘**인지 (뽑기권을 다 쓴 상태) |
| 패배 | 'Defeat' 제목 + '재도전' 버튼 템플릿 |
| 소환 화면 / 결과 | 하단 탭, '30회' 버튼, '터치하여 닫기' 템플릿 |

### 안전장치
- **보석으로는 뽑지 않는다.** 30회 버튼 비용이 보석이면 이미 뽑은 미션으로 보고 누르지 않는다.
  (소환 미션 직전에 30회 뽑기권이 지급되므로, 정상이라면 비용은 항상 뽑기권으로 표시된다)
- `[반복]` 패널은 문구가 '소환'이어도 뽑지 않는다. 탭했는데 소환 화면이 열리면 그대로 빠져나온다.
- ESC는 **소환 화면에서만** 보낸다. 전투 화면에서 ESC를 보내면 게임 종료창이 뜰 수 있기 때문이다.
  화면이 닫히는 도중에 ESC가 한 번 더 들어가지 않도록 3초 기다린다.
- 사용자가 직접 연 화면(채팅, 상점, 소환 화면 등)은 건드리지 않고 기다린다.
- **MuMu 창을 최소화하면 자동으로 일시정지한다.** 최소화 중에는 ADB 캡처에 이전 화면이 섞여 오작동할 수 있다.
  다른 창 뒤에 두거나 창을 작게 줄이는 것은 괜찮다.
  (Windows 10에서 MuMu 창을 다른 창으로 완전히 덮고 2분간 확인: 화면이 실시간으로 갱신되고 수령·뽑기가 정상 진행됨.
  ADB는 창에 보이는 그림이 아니라 에뮬레이터 내부 화면을 캡처하기 때문)
- 로그: `logs/guide_YYYYMMDD.log`. 이상한 화면을 만나거나 2분 넘게 기본 화면이 아니면 캡처도 `logs/`에 저장한다.

## 설정값
`guide_auto.py` 상단의 `설정` 블록에 있다. 직접 바꾸고 싶으면 `guide_auto.py`를 고치지 말고,
같은 폴더에 **`user_settings.py`** 파일을 만들어 바꿀 값만 적는다. 이렇게 하면 자동 업데이트를 해도 유지된다.
```python
# user_settings.py 예시
RETRY_ON_DEFEAT = False     # 패배해도 재도전 안 누르기
UPDATE_CHECK_HOURS = 2      # 업데이트 확인을 2시간마다
```

| 이름 | 기본값 | 의미 |
|---|---|---|
| `INTERVAL_SEC` | 5 | 화면 인식 주기(초) |
| `AFTER_SUMMON_WAIT_SEC` | 10 | 30회 뽑기 후 대기(초) |
| `SERIAL` | "" | ADB 기기. 비우면 게임이 실행 중인 기기를 자동 선택 |
| `ADB_CANDIDATES` | MuMu 기본 경로 | `adb.exe` 탐색 경로 |
| `RESUME_SETTLE_SEC` | 3 | 최소화 해제 후 재개까지 대기(초) |
| `RETRY_ON_DEFEAT` | True | 패배 시 '재도전' 누르기 |
| `RETRY_LIMIT` / `RETRY_WINDOW_SEC` | 3 / 600 | 10분 안에 3번 패배하면 재도전 중단 |
| `AUTO_UPDATE` | True | 새 버전 자동 업데이트 |
| `UPDATE_CHECK_HOURS` | 1 | 실행 중 새 버전 확인 주기(시간) |
| `AUTO_RELAUNCH_GAME` | True | 게임이 꺼지면 다시 실행 |
| `STUCK_SEC` | 180 | 같은 화면이 이 시간(초) 넘게 그대로면 ESC 한 번 |
| `ADB_RESTART_AFTER` / `ADB_BACKOFF_AFTER` | 3 / 6 | ADB 연속 실패 시 서버 재시작 / 천천히 재시도 기준 |
| `*_TH` | – | 각 판정 기준값 (주석에 실측 점수 범위 기재) |

## 파일 구성
```
guide_auto.py        메인 루프 (단독 실행)

  close_text/        닫기 문구 이미지 (여기 넣은 파일은 모두 닫기 문구로 인식)

updater.py           자동 업데이트 (GitHub 최신 버전 확인, ZIP 으로 파일 교체)

requirements.txt     opencv-python, numpy
.vscode/             VS Code 실행 구성
```
